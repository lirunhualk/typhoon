# Typhoon Classroom Demo

这是一个面向高中物理课堂的 GitHub Pages 静态课件，用来演示台风中心低压、上升气流、风速与树木房屋破坏程度之间的关系。

## 本地预览

```powershell
python -m http.server 4173
```

然后打开 <http://localhost:4173/>。

## GitHub Pages

仓库根目录包含 `index.html`、`styles.css`、`script.js` 和 `.nojekyll`。启用 GitHub Pages 后，可从 `main` 分支根目录直接发布到：

<https://lirunhualk.github.io/typhoon/>
